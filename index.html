Недели 1–7 · Foundation

C# и рабочая база

01STARTИнструменты, терминал, Git и первый C#console
Изучить

.NET 10 SDK, IDE, `dotnet new/build/run`, типы, ввод-вывод; Git status/add/commit/log/diff.

Сделать

15–20 небольших console-задач и репозиторий `backend-learning` с чистой историей.

Готовность

Сам создаёт и запускает project, чинит compile error, объясняет working tree, index и commit.

02CONTROL FLOWУсловия, циклы, методы и debuggerdebug
Изучить

`if`, `switch`, loops, methods, parameters, scope, breakpoint и пошаговую отладку.

Сделать

Calculator, converter, «угадай число» и безопасный разбор пользовательского ввода.

Готовность

Не дублирует логику, находит ошибку debugger’ом и объясняет простой call stack.

03DATA IN MEMORYКоллекции, даты, nullable и JSONjson
Изучить

`List`, `Dictionary`, `HashSet`, strings, `Guid`, `DateTimeOffset`, enum, nullable, files и JSON.

Сделать

Console task manager с CRUD, фильтрацией и сохранением между запусками.

Готовность

Осознанно выбирает collection, обрабатывает пустой input и не глушит nullable warnings.

04OBJECTSООП без архитектурного театраCHECK 01
Изучить

Classes, constructors, encapsulation, composition, interfaces и exceptions.

Сделать

Разделить task manager на model, service и `ITaskRepository`; две реализации storage.

Контроль

За 90 минут без AI написать console app, отладить и защитить каждое решение.

05QUERIESLINQ, generics и функциональные элементыlinq
Изучить

Generics, delegates, lambdas, `IEnumerable`, LINQ и deferred execution.

Сделать

Фильтры, sorting, grouping, pagination и statistics для task manager.

Готовность

Пишет LINQ query, переписывает циклом и знает момент фактического выполнения.

06I/OAsync, cancellation и HTTP clientasync
Изучить

`Task`, `async/await`, `CancellationToken`, timeout, `HttpClient`; async ≠ parallel.

Сделать

Client к учебному API с cancellation и обработкой timeout/недоступности.

Готовность

Нет `.Result`/`.Wait()`, cancellation доходит до I/O, ошибки сети объяснимы.

07QUALITYUnit-тесты и командный GitxUnit
Изучить

xUnit, Arrange–Act–Assert, test doubles, branches, merge conflict и pull request.

Сделать

Regression test → fix для task manager; оформить первый полноценный PR.

Готовность

Tests запускаются одной командой, проверяют behavior; merge conflict решён самостоятельно.
