# Backend / 24

Одностраничная программа обучения backend-разработке для Кира.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

## Проверка

- Desktop: 1440 × 900.
- Tablet: 768 × 1024.
- Mobile: 320 × 720 и 375 × 812.
- Keyboard navigation, `prefers-reduced-motion`, print/PDF.

## Публикация

GitHub Pages с custom domain `kir.cocal.xyz`; DNS управляется через Cloudflare.
